# PiBenchmark

My custom performance benchmarking tool used for measuring the floating point operations per second (FLOPS) of a cluster of Raspberry Pi Model B microcomputers.

Performance benchmarks were also done with an isolated compute environment on the Yellowstone supercomputer.
